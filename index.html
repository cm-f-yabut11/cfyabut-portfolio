RiderSafe

A full-stack web app for motorcycle rider safety, scheduled check-ins, and emergency communication. I came up with the concept, led the planning, and built and deployed it with my group.

Try it: riders can customize their safety button like this. Tap it to send a check-in.

What I built

  • Sign-up and login with password hashing and PHP session management.
  • GPS check-ins using the browser’s Geolocation API, with missed check-in detection and adjustable monitoring intervals.
  • An emergency SOS system with AJAX dashboards, notifications, and Google Maps location sharing.
  • A responsive, mobile-first interface with a customizable safety button (color, size, sound, and text).

Result

The app was deployed and stayed publicly accessible for several months. I completed about 80–90% of the planned functionality.

Built with PHP, MySQL, JavaScript, HTML, CSS, AJAX, Google Maps, and the HTML5 Geolocation API.
